# 自动操作工具

基于 Python + PySide6 的自动鼠标、按键操作工具，支持脚本录制回放、OCR文字识别、定时执行等功能。

## 功能特性

- **鼠标自动操作**：移动、点击（左键/右键/双击）、滚轮、拖拽，支持缓动移动轨迹
- **按键自动操作**：单键、组合键、文本输入（支持中文）、按键保持
- **脚本录制与回放**：热键启停录制、鼠标移动/双击/拖拽/组合键/文本输入捕获、脚本保存/加载、回放速度倍率、循环执行、紧急停止
- **脚本编辑**：步骤列表展示、右键菜单操作、步骤编辑弹窗（支持坐标捕获/区域框选）、增删排序、拖动排序
- **OCR文字识别**：屏幕区域/全屏识别、多语言支持、识别结果作为触发条件
- **定时执行**：单次定时、循环间隔、每日定时，任务管理
- **悬浮窗**：运行状态显示、运行日志、即将运行操作预览、展开/收起、拖拽移动、自动避让
- **热键管理**：全局热键注册、自定义热键、冲突检测
- **数据存储**：sqlite3持久化存储，支持脚本导入/导出JSON

## 技术栈

- Python 3.10+
- PySide6 6.5+（GUI框架）
- sqlite3（数据存储）
- pyautogui（鼠标/键盘操作）
- pynput（事件监听/录制）
- keyboard（全局热键）
- RapidOCR（OCR文字识别，基于ONNX Runtime）
- APScheduler（定时调度）
- pyperclip（剪贴板操作）

## 安装步骤

1. 克隆项目
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python main.py`

## 快捷键

| 功能 | 默认热键 |
|------|---------|
| 启动/停止录制 | F9 |
| 启动/停止回放 | F10 |
| 紧急停止 | Esc |

## 项目结构

```
├── main.py              # 应用入口
├── 打包脚本.py           # PyInstaller打包脚本
├── requirements.txt     # 依赖列表
├── data/                # 数据目录（运行时自动创建）
│   ├── auto_mouse_key.db   # 数据库文件
│   ├── backups/            # 数据库备份
│   ├── logs/               # 日志文件
│   └── rapidocr/           # OCR模型缓存
├── src/
│   ├── 公共/             # 枚举定义、异常定义、数据结构、日志管理
│   ├── 数据访问层/        # 数据库管理器、DAO层、JSON序列化器
│   ├── 业务逻辑层/        # 执行器、控制器、服务层
│   └── 表现层/           # 主窗口（三栏布局）、各UI组件、悬浮窗、系统托盘
└── test/                # 测试脚本
```

## 打包

运行 `python 打包脚本.py`，生成的exe文件位于项目根目录。
