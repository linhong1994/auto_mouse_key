# 自动操作工具

基于 Python + PySide6 的自动鼠标、按键操作工具，支持脚本录制回放、OCR文字识别、定时执行等功能。

## 功能特性

- **鼠标自动操作**：移动、点击（左键/右键/双击）、滚轮、拖拽，支持缓动移动轨迹
- **按键自动操作**：单键、组合键、文本输入、按键保持
- **脚本录制与回放**：热键启停录制、脚本保存/加载、回放速度倍率、循环执行、紧急停止
- **脚本编辑**：步骤列表展示、参数编辑、增删排序、拖动排序、批量延时修改
- **OCR文字识别**：屏幕区域/全屏识别、多语言支持、识别结果作为触发条件
- **定时执行**：单次定时、循环间隔、每日定时，任务管理
- **悬浮窗**：运行状态显示、运行日志、即将运行操作预览、展开/收起、拖拽移动
- **热键管理**：全局热键注册、自定义热键、冲突检测
- **数据存储**：sqlite3持久化存储，支持脚本导入/导出JSON

## 技术栈

- Python 3.10+
- PySide6 6.5+（GUI框架）
- sqlite3（数据存储）
- pyautogui（鼠标/键盘操作）
- pynput（事件监听/全局热键）
- PaddleOCR（OCR文字识别）
- APScheduler（定时调度）

## 安装步骤

1. 克隆项目
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python src/main.py`

## 快捷键

| 功能 | 默认热键 |
|------|---------|
| 启动/停止录制 | F9 |
| 启动/停止回放 | F10 |
| 紧急停止 | Esc |

```
├── 数据访问层/      # 数据库管理器、DAO层、JSON序列化器
├── 业务逻辑层/      # 执行器、控制器、服务层
├── 表现层/         # 主窗口、各UI组件、悬浮窗、系统托盘

```
